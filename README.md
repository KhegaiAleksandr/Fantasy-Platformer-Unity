# 2D Fantasy Platformer

### Project Overview
This is a technical showcase of a 2D platformer built with **Unity 2022.3 LTS**. 
The project focuses on clean architecture, modern input systems, and physics-based character controllers. 
Developed as part of my professional portfolio for university admissions (Target: **KAIST / SKKU 2026**).

### Tech Stack
- **Engine:** Unity 2022.3 (URP)
- **Input:** Input System Package
- **Language:** C# (OOP principles)
- **Version Control:** GitHub
